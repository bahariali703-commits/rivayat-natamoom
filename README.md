# روایت‌های ناتموم

سایت ایستا و راست‌به‌چپِ فید رسمی `@rivayat_natamoom2006` است. این پروژه هیچ تصویر، ویدئو یا متن ساختگی تولید نمی‌کند. دادهٔ فید در `data/instagram-feed.json` نگهداری می‌شود و فقط از API رسمی اینستاگرام به‌روز می‌شود.

## استقرار خودکار

این مخزن را در Netlify به‌عنوان سایت موجود `rivayat-natamoom2006.netlify.app` متصل کنید. فایل `netlify.toml` انتشار ریشهٔ پروژه را مشخص کرده است. هر پوش به شاخهٔ پیش‌فرض، استقرار تازه ایجاد می‌کند.

## اتصال API رسمی اینستاگرام

در بخش Secrets مخزن، دو مقدار زیر را با دسترسی رسمی حساب حرفه‌ای تنظیم کنید:

| نام Secret | کاربرد |
| --- | --- |
| `INSTAGRAM_ACCESS_TOKEN` | توکن بلندمدت Instagram API با دسترسی خواندن مدیای حساب حرفه‌ای |
| `INSTAGRAM_USER_ID` | شناسهٔ Instagram User حساب `rivayat_natamoom2006` |

گردش‌کار GitHub هر سه ساعت اجرا می‌شود، ۱۲ پست آخر را از API رسمی می‌خواند، فایل داده را به‌روز می‌کند و تغییر را به شاخهٔ اصلی پوش می‌کند. Netlify سپس همان تغییر را به‌طور خودکار مستقر می‌کند.

برای ریلزی که URL فایل ویدئو در API در دسترس نباشد، سایت کاور واقعی و دکمهٔ «دیدن در اینستاگرام» را نمایش می‌دهد.

## کنترل نسخهٔ اولیه

در نسخهٔ اولیه، آخرین ریلز واقعی حساب با شناسهٔ `DcQvEyCiJVd` از دادهٔ حساب رسمی وارد شده است. کارت آن در سایت باز می‌شود، ویدئوی داخل صفحه را در صورت دسترسی URL نمایش می‌دهد و دکمهٔ مستقیم اینستاگرام به همان ریلز پیوند دارد. شش کارت Unsplash و تمام متن‌های داستانیِ ساختگی نسخهٔ Drop حذف شده‌اند.
